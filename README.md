# StreamLingDiv
The rise of streaming services such as spotify have made music consumption digitized, making the language of consumed music one representation of digital linguistic diversity. To quantify this StreamLingDiv utilizes aggregates top 200 charts of streamed songs per country and year from MGD+ (Seufitelli et al, 2023) and combines it with lyrics data from Song Genius available here (https://www.kaggle.com/datasets/carlosgdcj/genius-song-lyrics-with-language-information). We run two language identification models on the preprocessed lyrics (FastText and GlotLID) to get language tags and derive contry year language distributions. For each country and year, we calculate measures of diversity according to the Leinster-Cobbold Framework as done in Essfors (2025) using the ASJP (Wichmann et al, 2025). This repository hold the script needed to reconstruct the dataset.


1. Danilo B. Seufitelli, Gabriel P. Oliveira, Mariana O. Silva, & Mirella M. Moro. (2023). MGD+: An Enhanced Music Genre Dataset with Success-based Networks [Dataset]. Zenodo. https://doi.org/10.5281/zenodo.8086643
2. Wichmann, Søren, Eric W. Holman, Cecil H. Brown, Matthew S. Dryer, and Qibin Ran (eds.). 2025. The ASJP Database (version 21).
3. Essfors, Hannes. 2025. “Global Linguistic Diversity - Adapting the Leinster-Cobbold Framework from Ecology for Humanities Research” edited by T. Arnold, M. Fantoli, and  and R. Ros. Anthology of Computers and the Humanities 3:653–69. doi:10.63744/srhQaCwGo5mj.


# Pipeline
To replicate the dataset construction, put the MGD+ and Lyrics data in raw. Then, run ´processing/database_processing/fetch_asjp.R` and `../fetch_glottolog.R`. This downloads the linguistic databases from the CLLD.

Then, run `processing/language_distributions/structure_raw_data.R`, to take the MGD stream data and create a .csv with the number of streams of a given artist and title combination in a specific country and year, and a .csv with the unique artist and title (i.e., songs) in the data. These are located in `data/processed/`.

In the next step, run `processing/language_distributions/add_lyrics_exact_match.R` to join the stream data with the lyrics data on the title and artist columns. Run `../add_lyrics_with_normalization.R` to apply a normalization on both artist and title in both the lyrics and stream data to find more matches. This includes removing any secondary artists, text following latin demarcation signs (e.g. - ), etc. All matches with lyrics are then joined together and fed to the language identification model in `processing/language_distributions/apply_LID.py`. Here two language identification models with multilingual capabailities (Fasttext (NLLB) and GlotLID) are both applied to the lyrics which first is subjected to preproceessing by removing stopsigns and vocalizations, lower-caseing, deduplication and text indicating part of song, e.g., verse. For each lyrics, the most probable language label from each model is saved together with the confidence of the prediction. In `../generate_language_distributions.R` low confidence predictions by fasttext are filtered away, and cases where GlotLid is more confident than fasttext is used. The final dataset with year, country, artist, title, language label and streams are placed in `data/final_dataset/`. 

Then, run `processing/database_processing/process_glottolog.R` and `../asjp_processing.R` to prepare the linguistic data to generate diversity measures. Run `processing/language_distributions/add_meta_data.R/` to add language meta data from glottolog to each language and country data from Natural Earth. This allows for linguistic and geographical analysis and interoperability. Finally, run `processing/diversity_measures/generate_diversity_measures.R` to construct a .csv with year country diversity measures.
